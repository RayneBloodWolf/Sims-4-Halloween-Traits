Five favorites from the 20-trait Halloween pack, released as standalone traits with custom icons. Family-friendly, CAS Emotional traits, Teen and up. Confirmed working in-game.

## Install
1. Download **HalloweenTraits-FeaturedFive-v1.1.zip** and unzip it, then unzip the five trait zips inside.
2. Place the five `.package` files in **Documents > Electronic Arts > The Sims 4 > Mods** (one folder deep max).
3. Game Options > Other: enable **Custom Content and Mods**. Restart the game.

**Note:** these are the standalone versions of traits that also live in the full Halloween Traits 20-pack — same tuning IDs. Install these five *or* the 20-pack, never both.
