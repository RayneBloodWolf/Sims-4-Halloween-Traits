## Install
1. Download **HalloweenTraits-FeaturedFive-v1.1.zip** and unzip it, then unzip the five trait zips inside — or grab the all-in-one **HalloweenTraits-FeaturedFive-Pack-v1.0.zip** instead.
2. Place the `.package` file(s) in **Documents > Electronic Arts > The Sims 4 > Mods** (one folder deep max).
3. Game Options > Other: enable **Custom Content and Mods**. Restart the game.

**Note:** the combined pack and the five standalone files are the same traits with the same tuning IDs — install one form *or* the other, never both.
